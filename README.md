# Project Overview

An offline AI-powered personal knowledge system built with **Next.js** and **Ollama**.
The application allows users to upload, edit, organize, and query documents locally with semantic search and interactive knowledge visualization.

## Features

* Upload documents in multiple formats (`.pdf`, `.txt`, `.md`)
* Local AI chat with document context
* Interactive knowledge graph
* In-app document editor
* Semantic vector search
* Fully offline and privacy-focused
* Automatic re-indexing after edits

## Tech Stack

* Next.js (App Router)
* Ollama
* Vanilla CSS
* Local JSON Vector Store
* JavaScript API Routes

## Workflow

1. Upload documents
2. Parse and chunk text
3. Generate embeddings with Ollama
4. Store vectors locally
5. Ask questions and retrieve relevant content

## Goal

Create a secure, local-first AI workspace for managing and exploring personal knowledge without external APIs or cloud storage.
